5) መጻሕፍት እና ኮፒዎች (Books & Copies)
---------------------------------------------------------------------
እያንዳንዱ መጽሐፍ የራሱ ኮፒዎች (copies) አሉት — ኮፒ በተማሪ ሲወሰድ ራሱ
"borrowed" ይሆናል፣ ሲመለስ ደግሞ "available" ይመለሳል። ኮፒ ከተበላሸ
ወይም ከጠፋ (damaged/lost) አድሚኑ በቀላሉ ደረጃውን መቀየር ይችላል
(Books → Edit / Manage Copies → ኮፒውን ይጫኑ)።
የመጽሐፍ ሽፋን (cover image) ከኮምፒውተርዎ ወይም ስልክዎ ላይ በቀጥታ
መጫን (upload) ይቻላል — URL መጻፍ አያስፈልግም።
4ቱ ዓይነቶች፦ Teacher Guide, Student Reference, General Books,
Student Text Books። ደረጃ (quality) ከ1-5 በአድሚኑ ይሰጣል።

ይቻላል)። ቀኑ ያለፈባቸው ተማሪዎች በ Dashboard ላይ በቀይ ቀለም ይታያሉ።
